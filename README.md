Demonstração prática de transição visual com **efeito Parallax** construído exclusivamente com propriedades nativas de **CSS3**, sem dependência de JavaScript ou bibliotecas externas.

---

## 🎯 Objetivo

Criar uma experiência imersiva de rolagem onde camadas de imagem de fundo se movem em velocidades diferentes do conteúdo em primeiro plano, demonstrando o uso avançado de propriedades visuais de background em CSS.

---

## ✨ Funcionalidades

- **Parallax Nativo**: Uso de `background-attachment: fixed` e `background-size: cover` para fixação dos planos de fundo.
- **Alternância de Camadas**: Transição harmoniosa entre imagens fotográficas em tela cheia e blocos de texto explicativo.
- **Leveza e Desempenho**: Renderização acelerada diretamente pelo motor gráfico do navegador com zero overhead de scripts.

---

## 🧰 Stack

- **HTML5**: Estruturação de seções com containers e classes de conteúdo.
- **CSS3**: `background-attachment: fixed`, `background-position: center`, dimensionamento relativo (`vh` e `%`) e tipografia fluida.
